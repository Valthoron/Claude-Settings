# Prepositions - Microsoft Style Guide | Microsoft Learn

## Prepositional phrases

A prepositional phrase is a combination of a preposition and a noun that modifies or describes some part of a sentence. In the following sentence:

>
> The reading pane displays the content of the selected message.

The prepositional phrase, *of the selected message,* describes the noun, *content.*

Avoid joining more than two prepositional phrases. Long chains of prepositional phrases are hard to read and easy to misinterpret.

## Placement in the sentence

It's OK to end a sentence with a preposition when it improves readability.

**Examples** Use a different instrumentation key for each environment that your application runs in. Specify which event hub you want to send the data to.

## Prepositions with UI elements

Whether you use *in* or *on* as the preposition for a UI element depends on what the element is.

| Element | Preposition |
| --- | --- |
| bar (command bar, search bar, taskbar, toolbar) | on |
| box (list box, search box, text box) | in |
| command line | on |
| dialog | in |
| list | in |
| menu | on |
| page | on |
| pane | in |
| ribbon | on |
| search results | in |
| system tray | in |
| tab | on |
| window | in |

**Examples** In the **Server name** box, enter the name that you copied earlier. In the **Create a deployment** pane, enter resource details. On the ribbon, select **Options**. On the toolbar, select **File** &gt; **Save**.
