# Writing step-by-step instructions - Microsoft Style Guide | Microsoft Learn

These guidelines help you create clear, easy-to-follow instructions.

## Scannability

- Consider using headings to help customers find instructions quickly. The headings should concisely describe what the instructions help customers do.
- Use parallel structure in headings. That is, use a consistent phrasing style.

    **Example** Create a profile Add an account
- If you use a sentence to introduce a procedure, make sure that the information is necessary. An introductory sentence shouldn't just repeat what the heading says.

## Multiple-step procedures

- Use a numbered list.
- If there's a chance of confusion, provide an introductory step that tells customers where to perform the action (for example, application, tool, or location in the UI).
- Use a separate step for each instruction. It's OK to combine short steps that occur in the same place in the UI.
- Most of the time, include actions that complete a procedure, such as selecting an **OK** or **Apply** button.
- Don't overwhelm customers with too many steps in a single procedure. Try to fit all the steps on the same screen.

**Example** To create a group of tiles:

1. On the **Start** screen, select the tiles that you want to group together.
2. Drag the tiles to an open space. When a gray bar appears behind them, release them to create the new group.

## Single-step procedures

A single step might not require list formatting. If you want to use a format that's consistent with step-by-step instructions in the same documentation, use a bullet instead of a number.

**Example** To move a group of tiles:

- On the **Start** screen, zoom out and drag the group to where you want it.

## Tips for writing steps

- Use a complete sentence. Capitalize the first word and use a period at the end.
- If you need to make sure that customers begin in the right place, provide a brief phrase at the beginning of the step. The rest of the time, start each sentence with an imperative verb.

    **Examples** On the ribbon, go to the **Design** tab. Open Photos.
- Make sure that customers know where the action should take place before you describe the action.

    **Examples** For **Alignment**, select **Left**. On the **Design** tab, select **Header Row**.
- Consider abbreviating simple sequences by using right angle brackets. Include a space before and after each bracket, and don't make the brackets bold.

    **Example** Select **Accounts** &gt; **Other accounts** &gt; **Add an account**.

    **Accessibility tip** Screen readers might skip over brackets and read instructions such as **Menu** &gt; **Go To** &gt; **Folders** as *Menu Go To Folders,* which might confuse customers. Check with an accessibility expert before you use this approach.
