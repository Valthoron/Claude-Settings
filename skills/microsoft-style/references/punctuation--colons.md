# Colons - Microsoft Style Guide | Microsoft Learn

Avoid using a colon to introduce a clarification or amplification of a sentence's main statement within the sentence itself. In most cases, you can make the sentence more direct and readable by rephrasing it or breaking it into multiple sentences. Alternatively, consider replacing the colon with a comma or an em dash, depending on the context. If the text after the colon has multiple parts, consider using a list instead. If you do use a colon within a sentence, the word after it should be lowercase unless it's a proper noun or the first word of a direct quotation.

**Examples**

| **Preferred (without a colon)** | **Acceptable (with a colon)** |
| --- | --- |
| The company is considering Los Angeles, Munich, and Tokyo for the event. | The company is considering three cities for the event: Los Angeles, Munich, and Tokyo. |
| If Exchange ActiveSync doesn't recognize the device, the device isn't properly connected, or it isn't a smartphone.ORExchange ActiveSync doesn't recognize the device for one of two reasons:• The device isn't properly connected.• The device isn't a smartphone. | Exchange ActiveSync doesn't recognize the device for one of two reasons: the device isn't properly connected, or it isn't a smartphone. |
| The cells of a worksheet can store different types of information—numbers, formulas, or text. | The cells of a worksheet can store different types of information: numbers, formulas, or text. |
| If you updated at least one value that requires approval, the Action Pane has two extra buttons, Proposed changes and Workflow. | If you updated at least one value that requires approval, the Action Pane has two extra buttons: Proposed changes and Workflow. |

## In titles and headings

Don't use a colon at the end of titles or headings. However, you can use a colon *within* a title, heading, or similar content (for example, an email subject line) to divide it into two parts that are analogous to a title and a subtitle. Always capitalize the word after the colon.

**Examples**

- Block party: Communities use Minecraft to create public spaces
- Get started with Azure IoT: An interactive developer guide

## Before images, tables, and code samples

Don't use a colon at the end of a phrase that directly precedes and introduces an image, a table, or a code sample. Use a period instead.

## Before lists

You can often use a colon at the end of a phrase that directly precedes and introduces a bulleted or numbered list, based on how strongly it looks ahead to the list items.

- If the phrase forms a complete sentence by itself:
    - You can typically use a colon when the sentence makes direct reference to the list items through expressions such as "here are," "these," "the following," or "as follows," or by stating the number of items.
    - Otherwise, use a period.
- If the phrase is a fragment:
    - Use a colon if at least one list item can be read immediately after the fragment to form a complete sentence.
    - Otherwise, don't add end punctuation to the fragment. In this case, you might consider formatting the fragment as a heading.

**Example** Make the transition easier by creating a backup of important things, such as:

- Installed apps
- Account passwords
- Call history

## In UI

In UI, don't use a colon at the end of headings, input labels, command names, or the labels for buttons, checkboxes, and other options.

Note

Even if a colon is used in UI, don't include it when you refer to the UI element by name in documentation.
